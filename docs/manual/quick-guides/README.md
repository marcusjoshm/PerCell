# Quick guides

Each quick guide is one job, start to finish, in as few steps as possible. For every control, follow the links to the chapters.

| Guide | Job |
|---|---|
| [Creating a dataset](create-a-dataset.md) | Turn a folder of microscope TIFFs into a PerCell dataset. |
| [Segmenting and measuring cells](segment-and-measure.md) | Find the cells with Cellpose and measure them. |
| [Finding puncta](find-puncta.md) | Detect puncta or condensates in each cell and count them. |
| [Running the single-cell workflow](single-cell-workflow.md) | Process many datasets in one run. |
| [Making lifetime masks](phasor-masks.md) | Select pixels by fluorescence lifetime on the phasor plot. |
| [Exporting results](export-results.md) | Save measurements, images and phasor data for other programs. |
